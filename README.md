# Capstone-Touchscreen-Project
STM32F4 microcontroller that interfaces with a touchscreen and QR scanner for a blood testing machine.

Our capstone project involved creating a blood testing machine. I was tasked with designing the user interface. Initially, I wrote firmware for the STM32F429i discovery board  to create the UI, interface with a QR scanner, and communicate the data to the motor controller via UART. I also created a PCB using the STM32F429VIT6 microcontroller to do the same tasks, but with a larger touchscreen.
