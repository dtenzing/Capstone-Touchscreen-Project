# Capstone-Touchscreen-Project
This repo contains the firmware for an STM32F429VIT6 microcontroller that interfaces with a touchscreen and QR scanner for a blood testing machine.

Our capstone project involved creating a blood testing machine. I was tasked with designing the user interface. Initially, I wrote firmware for the STM32F429i discovery board  to create the UI, interface with a QR scanner, and communicate the data to the motor controller via UART. However, due to the touchscreen on the discovery board being relatively small, I designed a custom PCB with the STM32F429VIT6 to interface with a bigger touchscreen.
